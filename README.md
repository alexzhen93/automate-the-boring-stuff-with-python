# 🐍 Automate the Boring Stuff with Python — Self Study

This repo documents my journey through **[Automate the Boring Stuff with Python](https://automatetheboringstuff.com/)** by Al Sweigart. I'm using it to review Python fundamentals and get back into tech after some time away — working through the exercises, practice projects, and my own notes along the way. The goal is to strengthen my Python foundation and continue developing the skills I use in QA automation and software engineering.

## 📌 Edition Notes

I'm working through the **2nd edition** first, since it's the version covered in the YouTube walkthrough I'm following along with. Once I finish it, I'll add the **3rd edition's new chapters** at the end as extra material:

- Database integration
- Speech recognition
- Audio/video editing

So the chapter list below reflects the 2nd edition structure for now — the 3rd edition chapters will be added on afterward, not merged in.

## 🎯 Goals

- Refresh core Python concepts: data types, control flow, functions, and data structures
- Get comfortable with practical, real-world scripting (files, regex, web scraping, automation)
- Review concepts relevant to QA automation and software engineering
- Build small projects to prove I understand each topic, not just recognize it
- Keep a record of my progress I can look back on
